# WAuto — АвтоРуководство ВАЗ

Обновлённая версия сайта с интерфейсом, стилизованным по предоставленному макету: тёмная гаражная тема, боковая навигация, верхняя панель поиска, карточки моделей, быстрый доступ, популярные поломки и руководства.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server
```

Все изображения, используемые в новом интерфейсе, находятся в `assets/images/ui/`, поэтому главная страница не зависит от внешних изображений.


## Обновления интерфейса
- Добавлено переключение светлой и тёмной темы; выбранная тема сохраняется в браузере.
- Интерфейс приведён к более строгой геометрии: прямые углы, аккуратные границы, меньше декоративных эффектов.
- Изображения неисправностей и запчастей сопоставляются по смыслу, а не подставляются случайным образом.
- Для моделей используются отдельные изображения из `assets/images/ui/`.

Если фотография не загрузилась, сайт показывает локальную заглушку. Изображения, которые загружаются по внешним ссылкам в `js/data.js`, требуют подключения к интернету.
